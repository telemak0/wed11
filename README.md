# Project description

Wed11 is an static website that allows their users to manage the lineups of their amateur football games. It also tracks wins and losses and other stats for each game. A single administrator user handles the creation of new accounts, the lineups of the game which are then shown in the frontpage and the results.

The project is hosted on Github pages which enforces an static website with an special database solution that does not require a server or hosting service.
